# AgeChecked Plus+ (Wordpress/Woocommerce Plugin)

## Description

This plugin provides age verification functionality for WooCommerce stores.

## Installation

1. Download the Plugin Zip File:
   - Download the latest release of the plugin from the [Releases](https://github.com/VerificoCode/Woocommerce/releases) page.
2. Upload to WordPress:
   - Log in to your WordPress admin panel.
   - Navigate to "Plugins" > "Add New".
   - Click on the "Upload Plugin" button.
   - Choose the downloaded plugin zip file and click "Install Now".
3. Activate the Plugin:
   - After installation, activate the plugin through the "Plugins" menu in WordPress.
4. Configure Plugin Settings:
   - Once activated, navigate to the plugin settings page to configure any necessary settings.
5. Start Using the Plugin:
   - Once configured, the plugin's features will be available in your WooCommerce store.

## Requirements

- WordPress 5.0 or higher
- WooCommerce 3.0 or higher (full High-Performance Order Storage/HPOS-aware
  behavior requires WooCommerce 8.7+; the plugin detects HPOS availability
  at runtime and falls back to legacy order storage on older versions)

## Frequently Asked Questions

### How do I access the plugin settings?

You can access the plugin settings by navigating to "Settings" > "AgeChecked Plus+ Settings".
